## Files and folders
@ code
+ files
!
On the left, the files of the project. A codecast can enlarge this panel when it talks about it, like now.
! {dir}
When it highlights a folder, that folder opens, and every other folder closes.
! {file}
+ zoom
When it highlights a file, the folders on the way to it open, and the rest stay closed. And when a page is big, the codecast can zoom in on the part it is talking about, like this.
!
+ sidebar-tabs
At the top of that panel, two tabs. The second one lists the items instead: every function, type and trait, module by module.
