## Reading code
@ code:{fn}
+ view
In the middle, the Code view. It shows a file as blocks: one per item, and inside a function, one per step. Click a block to open it.
! {fn}
+ zoom
A long file is easier to follow when the codecast zooms in on the block it explains.
!
+ source
= {fn_line}
On the right, the source. A codecast can underline the exact words it talks about. When you hover a block or a line, both sides light up.
+ split
At the top, next to the views, this button shows or hides the source.
