## アプリのあちこち
@ code
+ search
右上は検索ボックスです。名前の一部を入力すると、アイテムの一覧に一致するものだけが残ります。
+ codecast
その右のこのボタンで、コードキャストを開始または停止します。コードキャストのないプロジェクトでは、そのコードから作った組み込みツアーを再生します。
+ tour
その隣のこのボタンは、通しツアーを最初のパートから最後まで再生します。
+ generate
次は「生成」ページです。アプリを自分のマシンで動かしているときは、ここで自然な音声のコードキャストを録音できます。言語も複数選べます。
+ settings
右上の角にある「設定」では、テーマ、フォント、ビューの表示内容、音声、そして言語を変更できます。
+ help
そのすぐ左の疑問符を押せば、いつでもこのチュートリアルをもう一度見られます。
