## 自分のコードキャスト
```md Lines
| 行 | 働き |
|---|---|
| `@ flow:crate::run` | ビューを表示：ここでは `run` の制御フロー |
| `! crate::run/b2` | アイテム、手順、ファイル、フォルダをハイライト（`! src/store/`） |
| `= src/main.rs:12` | コードに下線を引く |
| `+ files` | パネルを拡大：`files`、`items`、`view`、`source` |
| `+ search` | アプリの一部を強調：`search`、`player`、`settings`… |
| `+ zoom` | ハイライトした部分にズーム（または `+ zoom files`、`+ zoom side`…） |
| `+` | 通常の表示に戻す |
| `? …とは？` | 質問。回答はその下に字下げして書く |
```
@ code
+
| md:Lines
^ codecast brief .
自分のプロジェクトにバーチャルな発表をつけるには、まずブリーフから始めます。プロジェクトに何があるかを、あなたや人工知能に伝える短いテキストです。
+ zoom side
右側のメモは、スクリプトの行の一覧です。スクリプトは、プロジェクトの横に置くマークダウンファイルです。一行に一文を書き、その上に、何を表示するかを示す短い行を置きます。
+
^ codecast check codecast.md
次に、すべての参照がまだコードを指しているかを確認し、
^ codecast serve .
配信します。これでチュートリアルはおしまいです。どうぞ楽しんでください。
