## ビュー
@ code
+ views
左上の「コード」の隣にある「ビュー」ボタンで、図を開きます。どの図もコードから作られ、コードが変わるとそれに追従します。
@ arch
+ view
真ん中はアーキテクチャです。モジュールごとにボックスが一つあり、あるモジュールが別のモジュールを使うところに矢印があります。ドラッグで移動、スクロールでズームし、F キーで全体表示に戻ります。
@ calls:{fn}
同じく真ん中は、呼び出しツリーです。エントリポイントから下へ、誰が誰を呼ぶかを示します。ボックスをダブルクリックすると、開いたり折りたたんだりできます。
@ flow:{fn}
! {fn_b1}
+ zoom
一つの関数の制御フローを、一歩ずつ表示します。分岐、ループ、早期リターンです。ここでは、コードキャストが話している手順にズームしています。
!
+ view
@ types
型とトレイトです。何が何を持ち、誰が何を実装しているかを示します。
@ errors
エラーフローです。どの関数がエラーを返し、どこで疑問符がエラーを上に渡し、どこで処理されるかを示します。
+ source
右側は、選んだものの詳細です。シグネチャ、ドキュメント、呼び出し先、呼び出し元、そしてソースです。
