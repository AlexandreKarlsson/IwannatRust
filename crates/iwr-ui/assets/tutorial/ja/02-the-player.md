## プレーヤー
@ code
+ player
画面の下にあるこのバーが、プレーヤーです。space キーで一時停止と再開、矢印キーで一文ずつ戻ったり進んだりできます。
+ caption
バーの中央には、話している内容が文字でも表示されます。読みながら聞くことも、聞かずに読むこともできます。
+ parts
文字のすぐ上には、コードキャストのパートが並びます。通しツアーではすべてを順に再生します。一つだけ再生することもできます。
+ voice
左下は音声です。この声のような自然な音声の録音、ブラウザ音声、または音声なしを選べます。音声なしなら、自分のペースで読めます。
+ lang
そのすぐ隣は言語です。コードキャストは翻訳して、別の言語で読み上げることもできます。ボタンなどの表示言語は、上のバーで切り替えます。
