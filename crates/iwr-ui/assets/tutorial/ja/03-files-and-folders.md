## ファイルとフォルダ
@ code
+ files
!
左側は、プロジェクトのファイルです。いまのように、コードキャストは話題にするときにこのパネルを大きくできます。
! {dir}
フォルダをハイライトすると、そのフォルダが開き、ほかのフォルダはすべて閉じます。
! {file}
+ zoom
ファイルをハイライトすると、そこまでの途中のフォルダが開き、ほかは閉じたままです。ページが大きいときは、こうして話している部分にズームすることもできます。
!
+ sidebar-tabs
パネルの上には、タブが二つあります。二つ目のタブでは、アイテムを一覧表示します。関数、型、トレイトのすべてを、モジュールごとに並べます。
